# _legacy — Phase 1 (Summer 2026) archive

This is **not a graveyard — it's the origin story.** These are the Version 1 artifacts from the
log's first purpose (Summer 2026): rebuilding the code fluency behind an AI-assisted accounting
portfolio. They're preserved intact so the repository shows a real evolution rather than pretending
V2 existed from the start.

- **`datacamp-2026-summer/`** — the Tier-A interview compilation, the Tier-A learning synthesis, the
  translated/active-review of the summer DataCamp courses, and the original H2-2026 learning plan +
  roadmap supplement. Still useful as retrieval material; no longer the active roadmap.
- **`sessions-v1/`** — the original session-report system, superseded by the source-neutral
  `ACTIVITY-TEMPLATE.md` at the repo root.

Nothing here is dead. It's Phase-1 evidence, and the phase model in `ROADMAP.md` points back to it.
